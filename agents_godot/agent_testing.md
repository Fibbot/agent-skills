# agent_testing.md

## Purpose
Define testing strategy, coverage requirements, and validation patterns for all game systems. Ensure deterministic correctness, balance integrity, and system reliability across client and server.

## Scope
- Unit testing for game math and systems
- Integration testing for API and data flow
- Deterministic replay verification
- Balance and edge case validation
- Load testing for leaderboards and concurrent runs
- Client UI testing patterns

## Output Requirements
1. **Test coverage targets** — Critical systems at 90%+ coverage, game math at 100%.
2. **Deterministic proof** — Every run simulation test verifies identical output from identical inputs.
3. **Edge case catalog** — Documented boundary conditions with corresponding test cases.
4. **Performance baselines** — Load test benchmarks for API endpoints and leaderboard queries.
